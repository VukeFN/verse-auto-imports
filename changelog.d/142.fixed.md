**Listeners and timers are released on deactivation**: the CodeLens provider's configuration and document-change listeners, the status bar's configuration listener, and any armed auto-import debounce timer are now torn down with the extension. A pending auto-import can no longer edit a file after the extension is disabled or the window is reloaded, and the CodeLens provider no longer keeps handling every keystroke in every open document once it is gone. As part of the same fix, a path conversion lens no longer disappears from under the cursor: hovering a non-import line armed a hide that nothing could cancel, so moving straight onto an import could blank its lens once the hide delay elapsed.
