**Path conversion CodeLens**: a `using` inside a `<# ... #>` block comment, or one indented inside a module body, no longer gets a Use relative path / Use absolute path lens, no longer counts towards the convert-all lens, and is no longer touched by Use relative paths for all / Use absolute paths for all. The provider and the converter now read the same import scanner the rest of the extension uses. As part of that agreement, a file-level folder import written as a bare identifier, such as `using { Features }`, now gets a lens where it previously got none.
