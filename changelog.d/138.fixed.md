**Project path cache setting**: turning `cache.enableProjectCache` off now really disables the cache. Rebuild Project Path Cache and Clear Project Path Cache report that it is off instead of scanning the project and writing a cache no watcher can invalidate, Show Cache Status reports it as disabled rather than as not loaded, a cache an earlier session stored is dropped rather than left in workspace storage where nothing can reach it, and toggling the setting offers the window reload it needs to take effect.
