**New Imports No Longer Land Above the Import That Provides Them**: adding an import to a file whose imports are split into blank-line-separated groups now places it in the group the whole file's ordering calls for, instead of always the first group. A dotted import such as `using { Economy.Shop }` was inserted into the top group even when the `using { Features }` that brings `Economy` into scope sat in a group below it, and because Verse reads `using` statements top-down the file then failed to compile with the same "Unknown identifier" error the import was meant to fix. A bare provider added for a dotted import still lands above it, and with **Sort Imports Alphabetically** turned off new imports are appended after the last group rather than the first
