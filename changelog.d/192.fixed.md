**Duplicate imports around an anchored line**: **Optimize Imports** no longer writes a second copy of a path that an import anchored by a comment marker already provides. A file holding both such an anchored import and an ordinary import of the same path was left importing it twice, once at the top and once at the anchored line; the ordinary one is now removed, along with any comment written for it. The duplicate is left alone in a file that also imports a module by a bare or dotted name, where removing it could stop the file compiling.
