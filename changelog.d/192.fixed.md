**Optimize Imports No Longer Imports the Same Path Twice**: organizing a file that contains both an import anchored by a comment marker (one whose line opens a `<#` or `<#>` comment over the lines below it) and a second, live import of the same path now leaves one import of it. Previously the live one was hoisted into the rebuilt block anyway, leaving the file importing the path twice - once at the top and once at the anchored line. A comment written above or trailing the dropped duplicate is dropped with it, since it annotates a statement that no longer exists. Where any other import left in the block is not an absolute `/Path`, the duplicate is kept instead: the anchored line ends up below the block, so removing the copy above it could leave a dotted import such as `using { Economy.Shop }` without the `using { Features }` that brings `Economy` into scope.
