**Duplicate imports around an anchored line**: **Optimize Imports** no longer writes a second copy of a path that an import anchored by a comment marker already provides. A file holding both such an anchored import and an ordinary import of the same path was left importing it twice, once at the top and once at the anchored line; the ordinary one is now removed, along with any comment written for it. It is kept where the file also holds a `using` that is not an absolute path, because the anchored line ends up below the rebuilt import block and such a `using` may need the removed copy above it to resolve.
